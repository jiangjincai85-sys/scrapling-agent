CONFIDENCE RATING

三层置信度评估体系

不同价值的场景用不同深度，不浪费你的时间。

可信度 = 来源评估 (30%) × 内容评估 (40%) × 共识验证 (30%)
内容权重最高 · 有数据的博客比空话的官网更可信
第一层 · 来源评估
域名信誉 + 作者 + 平台
爬之前判断 → 决定爬不爬
第二层 · 内容评估
信息密度 + 证据 + 时效
爬之后判断 → 权重最高 40%
第三层 · 共识验证
多源交叉验证
多条独立来源一致 → 加分

按价值自适应评估等级

L1·快速
只看来源
~28 秒
  • 只评估来源域名和作者
  • 不做内容验证
  • 可靠度：🟠 仅参考方向
  • 适合「随意浏览」的场景
L2·标准 ✅ 默认
来源 + 内容
~36 秒
  • 评估来源 + 爬取内容质量
  • 剔除空洞文章
  • 可靠度：🟢 有参考价值
  • 适合「方向参考」的场景
L3·深度
全三层交叉验证
~46 秒
  • 多源交叉对比消除偏见
  • 发现矛盾会标红提示
  • 可靠度：🔵 可作决策依据
  • 适合「决策分析」的场景
💡 智能升级/降级： 来源分低但内容好 → 自动升级到 L3 加共识验证。
所有来源都很权威 → 可降级跳过重复验证。
发现矛盾信息 → 强制 L3 必须交叉验证。

综合等级对照

综合分等级说明

TECH STACK

背后技术栈

基于 Scrapling 自适应爬虫库构建，GitHub 近 9K Stars。

🔍 搜索引擎

先找到信息在哪儿。基于关键词自动检索多个搜索引擎，定位目标页面。

🕸️ Scrapling Fetcher

普通页面抓取。快速获取页面内容，处理标准 HTML 页面。

🛡️ StealthyFetcher

处理有 Cloudflare 反爬机制的页面。模拟真实浏览器行为。

⚡ DynamicFetcher

需要 JS 渲染的动态页面。执行 JavaScript 后再提取内容。

📊 置信度算法

三层加权评分体系。来源30% + 内容40% + 共识30%，内容权重最高。

📝 输出格式化

每条结果带来源链接、置信度分数、评估明细。末尾附完整引用附录。

依赖安装

如需手动安装 Scrapling 爬虫依赖库。

pip install scrapling

# 验证安装
python3 -c "import scrapling;
print(scrapling.__version__)"

# 浏览器渲染（可选）
pip install playwright
playwright install chromium
